# heart_animation_for_programmers

Веб-анимация сердца в программистском оформлении. Небольшой Flask-сервер отдаёт страницу из HTML-шаблона.

## Запуск

```sh
python -m pip install flask
python main.py
```

Откройте `http://localhost:8080/heart`. Страница находится в `templates/index.html`, фоновое изображение — в `static/images/matrix.jpg`.
